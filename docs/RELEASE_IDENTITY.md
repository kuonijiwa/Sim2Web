# Software identity and retained evidence

The current software display name is **SimWebView**. The title used for software
citation is **SimWebView: Web-based visualization of large geotechnical
simulation models**.

The owner renamed the repository to https://github.com/kuonijiwa/SimWebView. The Python
package `geosimvis`, npm package identifier, imports, example directory names,
model filenames and array names are retained for compatibility. The npm
`private: true` setting prevents accidental npm publication; it does not make
the GitHub repository private.

The numerical package is version 0.1.0-alpha.0 (Python-normalized form 0.1.0a0),
publication revision 2. The interface translation is dated 2026-09-16. The
SimWebView name alignment changes publication documentation and citation
metadata, not numerical processing or frontend behavior.

The `paper_evidence/` files are historical records, not newly generated results
for the name change. Their names, hashes, messages and original screenshots are
retained. Recorded byte-identical regeneration refers to the numerical outputs
of those original repeated runs, not to the renamed documentation package.

Current interfaces and processor text are English. Historical screenshots may
predate that update and are not retouched to imply a new validation run.

Code and project documentation use MIT. Example datasets and case evidence use
CC BY 4.0. Copyright remains HydroChina Itasca. Software citation authorship is
recorded separately in `CITATION.cff`.

This folder is prepared locally for upload. No public commit, release date or
archive DOI is invented. Assign and record those identifiers after the actual
upload and release checks. The submission manuscript is maintained separately
and is not included or modified by this package preparation.
